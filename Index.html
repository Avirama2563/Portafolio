Acerca de mí

Soy Esteban Alexis Avirama Lopez, estudiante y desarrollador Full Stack en formación. Me interesa el desarrollo de software porque une dos cosas que disfruto: resolver problemas con lógica y construir cosas que otras personas puedan usar de verdad.

Trabajo tanto en la capa visual de una aplicación —cuidando que la interfaz sea clara y agradable de usar— como en la lógica que ocurre detrás: servidores, bases de datos y la comunicación entre ambos mundos. Me gusta entender el problema completo antes de escribir la primera línea de código.

Este portafolio reúne mi perfil profesional, la formación y las habilidades que estoy construyendo, y los proyectos en los que he trabajado.

Perfil profesional

Ocupación de referencia (CUOC): 25120 — Desarrolladores de software

Investigo, analizo y evalúo los requisitos de aplicaciones y sistemas, y diseño, desarrollo, pruebo, mantengo e implemento soluciones de software optimizando recursos y tiempo de acuerdo con los requerimientos del proyecto. Puedo desempeñarme en organizaciones de tecnología, firmas consultoras o equipos de desarrollo internos, cubriendo tanto el front-end como el back-end de una aplicación.

Qué hago

  • Diseño la arquitectura de una aplicación: cómo se conectan la interfaz, el servidor y la base de datos.
  • Desarrollo e implemento interfaces de usuario con HTML, CSS y JavaScript, y las conecto a servicios reales.
  • Construyo la lógica del servidor y gestiono el acceso y almacenamiento de datos.
  • Pruebo y valido que el software funcione como se espera antes de entregarlo.
  • Reviso y corrijo errores, y ajusto el rendimiento de aplicaciones ya existentes.
  • Interpreto necesidades de experiencia de usuario para mejorar el diseño de una herramienta.

Formación

Formación académica: Profesional en Ingeniería de Sistemas, Ingeniería Informática, Ingeniería de Software o Tecnología en Análisis y Desarrollo de Software.

Conocimientos específicos:

  • Dominio de HTML5, CSS3 y JavaScript.
  • Manejo de frameworks front-end como React, Angular o Vue.js.
  • Tecnologías de back-end como Node.js, Python, Java o PHP.
  • Diseño y administración de bases de datos SQL y NoSQL.
  • Diseño de interfaces (UI/UX) con herramientas como Figma.
  • Principios de usabilidad y accesibilidad web.
  • Control de versiones con Git y flujos de despliegue (CI/CD).
